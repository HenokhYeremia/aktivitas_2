## Tentang Project

**Praktikum Aktivitas 2 PAB** adalah aplikasi Flutter sederhana yang dibuat sebagai latihan pengembangan antarmuka mobile. Project ini menggunakan konsep **music player UI** dengan tiga halaman utama, yaitu **Home**, **Music**, dan **Profile**.

Seluruh tampilan utama aplikasi dibangun di dalam `lib/main.dart` menggunakan komponen Material Flutter. Desain aplikasi memakai kombinasi warna **dark blue**, **grey**, dan ikon musik untuk menghasilkan tampilan yang minimalis, rapi, dan mudah dipahami.

---

## ✨ Fitur Utama

- 🏠 **Home Page** dengan grid item bernuansa musik
- 🎵 **Music Page** dengan album placeholder dan tombol play
- 👤 **Profile Page** dengan ikon profil sederhana
- 🧭 **Bottom Navigation Bar** untuk berpindah halaman
- 📱 **Responsive UI** menggunakan `SafeArea`, `Expanded`, dan `GridView`
- 🌙 **Dark Theme Styling** pada bottom navigation
- 🔲 **Grid Layout** dengan 2 kolom

## Penjelasan UI

### 🏠 Home Layout

Halaman **Home** menampilkan judul `PRAKTIKUM PAB` di bagian atas, kemudian grid berisi 6 item dengan ikon musik. Grid dibuat menggunakan `GridView.count` dengan 2 kolom, jarak antar item yang rapi, serta background abu-abu pada setiap item.

### 🎵 Music Page

Halaman **Music** menampilkan area album berbentuk kotak vertikal berwarna grey dengan ikon album di tengah. Di bawahnya terdapat tombol **Play Music** sebagai elemen utama dari tema music player.

### ▶️ Button Play Music

Tombol **Play Music** menggunakan `ElevatedButton` dengan warna abu-abu, teks hitam, font bold, dan border radius kecil agar tampil clean dan modern.

### 🧭 Bottom Navbar

Navigasi bawah menggunakan `BottomNavigationBar` dengan 3 menu:

- Home
- Music
- Profile

Navbar menggunakan warna background **dark blue** `#172033` dan ikon putih agar kontras dengan tampilan aplikasi.

### 🎨 Styling Warna

Project menggunakan gaya visual sederhana:

- **Dark blue** untuk bottom navigation
- **Grey** untuk kartu grid, album placeholder, dan tombol
- **Black/white contrast** untuk teks dan ikon
- **Rounded corner** kecil untuk tampilan modern
